# 安全与隐私

[返回首页](../README.md) · [日常操作](operations.md) · [贡献指南](../CONTRIBUTING.md)

本文说明当前实现的信任、认证与存储边界，不是全面安全审计或所有上游版本的安全保证。实际检查范围见 [implementation-plan](implementation-plan.md)。

## 信任边界

dsh 能访问工作目录、运行工具和命令。面板能启动进程、安装软件、管理 SSH 隧道，应按本机用户权限下的敏感控制入口对待。

- 面板后端绑定 `127.0.0.1`，使用系统分配端口，并校验启动令牌及请求的 Host/Origin。
- 远端 dsh 保持远端 loopback 监听，通过 SSH 隧道访问；不增加公网监听或互联网反向代理入口。
- loopback 和同源校验能缩小暴露面，**不能防住已能读取本机用户文件的恶意进程**，也不能替代 SSH 主机身份校验。
- 面板鉴权与 dsh 自身的入口鉴权是两套机制；SSH 身份验证仍由用户现有 SSH 配置和密钥设施负责。

SSH 使用 `StrictHostKeyChecking=yes`，不自动信任新主机。首次连接须自行向管理员核对指纹并完成 SSH 配置；发现指纹变化应先核实，不关闭验证来绕过错误。

## 长期密钥不存配置，不代表认证信息不落盘

实例配置只保存连接信息和密钥路径引用，不应包含密码、私钥内容或 API key。余额功能可使用现有 `DEEPSEEK_API_KEY` 环境来源或 dsh 凭据存储；本项目不要求把密钥复制进实例 JSON。

以下位置可能包含敏感信息，**不是问题报告附件**：

| 位置 | 应如何对待 |
| --- | --- |
| `state/app.json`、`state/app-owner.json` | 保存面板认证或进程所有权及上下文信息；当作敏感运行文件保护 |
| `state/` 中的实例记录、余额缓存 | 可能包含认证 URL、主机信息或账户数据，不打包上传 |
| `logs/`、远端 dsh 日志 | 可能包含启动链接、路径、命令输出和认证信息，不直接复制到工单 |
| `browser-profile/` 或实际浏览器 profile | 可能保存 Cookie 与会话，不共享或提交 |
| dsh 自身凭据目录 | 由 dsh 管理的密钥与账户材料，不读取后粘贴，不纳入仓库 |
| 远端 `.dsh/remote-web.url`、`.dsh/remote-web.log` | 运行时发布的入口与日志，按敏感文件处理 |

Git 忽略规则只避免误提交，不加密文件、不阻止同账户进程读取，也不保证备份或同步软件会排除它们。不要把安装目录及运行状态整体作为“诊断包”。

## 鉴权、刷新与显示

启动凭据通过入口 URL fragment 交给页面，页面立即清理地址并保存在内存中；fragment 不作为普通 HTTP 查询参数发送。API 不接受 query token，使用 Authorization 请求头，首次建立同源 HttpOnly、SameSite=Strict 会话 cookie，刷新页面仍可鉴权，不把 key 存入 localStorage。

静态 HTML/JS 不注入秘密；API 结果、日志视图和任务信息默认脱敏，普通复制去除 URL 查询参数与 fragment。打开 dsh 时的内部认证仍需使用其完整入口，因此不承诺认证信息完全不落盘；浏览器、运行时文件和上游输出仍需保护。

不要把 `url`、`status`、`logs` 或 `doctor` 的原始输出直接用于报告，也不要分享面板/dsh 的完整入口链接。截图前确认不含认证参数、个人主机信息或账户数据；旧面板截图不作为当前界面证明。

## 网络与安装副作用

本项目不增加遥测或托管控制面，但“本地面板”不等于离线。功能可能触发：

| 功能 | 可能的访问或变更 |
| --- | --- |
| 实例探测、启动、日志 | SSH 访问已配置主机；隧道与进程状态写入本地 |
| 版本检查、dsh 安装/升级 | npm registry 及 npm 配置的来源；显式安装/升级会改变软件 |
| Node 准备 | nodejs.org 或 `DSH_NODE_MIRROR` 指定来源；下载包及校验清单 |
| 余额 | DeepSeek 账户接口；账户信息缓存，不是通用健康检查 |
| 面板/托盘轮询 | 可重复触发探测；不是每次网络访问都来自即时点击 |

Node 安装流程使用发布清单中的 SHA-256 核对压缩包；镜像与校验清单仍必须来自可信来源，校验通过不等于整条软件供应链已经受审计。dsh 自身的联网行为与依赖不在面板零第三方依赖承诺之内。

`autoInstall:false` 只限制远端 `start` 自动安装软件和部署服务，不是阻止显式 `install` 或 `upgrade` 的权限系统。安装、服务运行和停止范围见[日常操作](operations.md)。

## 报告问题与疑似泄露

仅提供发生时间、组件/版本、无认证参数的步骤、错误类别及预期/实际结果。路径和主机标识也要按实际需要最小化；不要先上传原始文件再指望平台替你脱敏。

疑似泄露时，先停止传播相关材料，并由所有者撤销或轮换对应凭据、更新受影响会话。公开问题中只描述影响范围和复现条件，不附可用密钥、Cookie、认证链接或完整凭据文件。

历史认证机制的研究见[档案索引](archive/README.md)；旧文“已验证”只适用于当时版本和环境，不能推导当前版本的支持或安全保证。
